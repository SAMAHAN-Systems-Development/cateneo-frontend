# Cateneo Frontend Repository

## Description

Official frontend repository for the **Cateneo Website**, built with **Next JS**

## Pre-requisite Installations

Install the following:

- Git

- Node.js

- VSCode

VSCode Extension:

- Prettier (VSCode Extension)

- ESlint

## Project setup

1. Clone the repository

```bash
$ git clone https://github.com/SAMAHAN-Systems-Development/cateneo-frontend
```

2. Fetch the updates

```bash
$ git fetch
```

3. Change Directory to "cateneo-frontend"

```bash
$ cd cateneo-frontend
```


4. Install the libraries with this command:

```bash
$ npm i
```

5. Paste the .env

## Running Application

1. Pull from the main for updates

```bash
$ git pull origin main
```

2. Install the libraries with this command:

```bash
$ npm i
```

3. Run the Server with this command:

```bash
$ npm run dev
```
